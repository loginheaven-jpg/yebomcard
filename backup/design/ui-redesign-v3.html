제 추천 — S안 (행동 결합) + T안 hint 결합

사용자 제안인 S안이 가장 실용적이지만, T안의 지능형 hint를 결합하면 더 강력해집니다:

S+T 결합 동작:
  1. 입력칸에 텍스트 입력 → parseReference로 자동 추론
  2. 장절 형식이면 [본문검색] 버튼이 굵게 강조
  3. 한글 단어 형식이면 [주제추천] 버튼이 굵게 강조
  4. 사용자는 추천대로 누르거나, 다른 버튼으로 의도 명시 가능
  5. Enter 키 = 추천된 액션 자동 실행
이점: 명시적 (S) + 빠름 (T) + 학습 비용 최소

U/V안에 대한 의견

  • U (Reading-First): 가장 미래지향적. 일반 성경앱 패턴. 단, 현재 검색 중심 사용자에겐 변화 큼. 향후 v2.0에서 시도 가능.
  • V (하단 탭바): 앱 표준이지만 본질적으로 PWA로 전환할 때 어울림. 현재는 도구함이 우상단에 있어 일관성 깨질 수 있음.
