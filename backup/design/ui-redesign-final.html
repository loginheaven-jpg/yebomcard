예봄성경 — 최종 UI 시안

사용자 제안 (S안 + 책갈피) 반영. 모드 탭 폐기 → 행동 직접화. 성경목차/책갈피 동일 비중 분리.

상단 ~190px

1. 첫 방문 시 최종

책갈피가 비어 있는 상태. 사용자에게 어떤 화면이 보이는지.
예봄성경
⇄
시작하려면 위에서 검색하거나 성경목차를 선택하세요
✦
🔖
구성 요소:
  • 줄 1: 브랜드 + 버전 셀렉터(주/대역) + 폰트 + 도구함
  • 줄 2: 검색 입력 + [본문검색] [주제추천] 버튼
  • 줄 3: [📚 성경목차] [🔖 책갈피] (50:50)
상단 ~190px

2. 책갈피 활성화

사용자가 시편 23편을 읽다가 닫고 다시 들어왔을 때.
예봄성경
⇄
책갈피 클릭 시 ↓
시편 23편으로 즉시 이동
🔖
책갈피 강조 효과: 활성화 시 노란 톤으로 강조 + 마지막 위치 + 시간을 부제에 표시. 사용자가 어디까지 읽었는지 한눈에. 클릭하면 본문으로 점프.
상단 ~190px

3. 본문 읽는 중 (자동 저장)

사용자가 시편 23편을 읽고 있는 상태. 책갈피가 자동 갱신 중.
예봄성경
⇄
시편 23편
1 여호와는 나의 목자시니
내게 부족함이 없으리로다

2 그가 나를 푸른 풀밭에
누이시며 쉴 만한 물 가로
인도하시는도다

3 내 영혼을 소생시키시고
자기 이름을 위하여 의의 길로
인도하시는도다
🔖
자동 저장: 본문 진입 후 3초 머물면 자동으로 책갈피 갱신. 사용자는 의식할 필요 없음.
성경목차 부제: 현재 위치도 표시되어 컨텍스트 보존 (시편 ▸ 23 ▸ 1절).

사용 흐름

① 첫 방문 → 책갈피 회색 ("아직 기록 없어요")
② 성경목차 → 시편 23편 진입 → 3초 후 자동 저장 → 책갈피 활성화 (노란 톤)
③ 다음날 재방문 → 책갈피 클릭 → 시편 23편으로 즉시 이동
④ 시편 51편으로 이동 → 책갈피 자동 갱신 (시편 51 · 방금)

기술 구현

저장 위치: localStorage["yebom_bookmark"]
구조:
{
  "book_code": "psa",
  "book_name": "시편",
  "book_abbr": "시",
  "chapter": 23,
  "verse": 1,
  "version": "nkrv",
  "savedAt": 1730878800000
}
저장 트리거: 본문 화면(SearchPanel chapter 모드의 verse 단계) 진입 후 3초 setTimeout
읽기: 첫 화면 마운트 시 localStorage 조회 → 책갈피 카드의 부제에 표시
점프: 책갈피 클릭 → 저장된 book/chapter로 setBookCode/setChapter
