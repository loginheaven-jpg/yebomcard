예봄성경 — UI 재설계 (v2)

코드 재검토 반영. 노란 점선 = 본문 시작 위치. 모바일 380px 폭 기준.

핵심 사실
• 버전 6가지: 개역개정, 새번역, 통독성경, KJV, NIrV, GNT
• 셀렉터 2개(주 + 부)는 글로벌 기준 — 검색·추천·본문 모두에 적용
• "병기" 버튼은 폐기됨 (부 셀렉터의 "대역" = none이 동일 역할)
• 우상단: T(폰트 설정), ⚙(도구함: 찬송가/예배성경/성경카드)
• 좌하단: 🔖 스크랩 FAB
• 모드 탭: 말씀 검색 / 장절 선택 / 주제 추천

B 추천 이유:

  • 정보 위계가 한눈에: 줄 1(브랜드/도구) → 줄 2(컨텍스트: 버전+모드) → 줄 3(액션: 검색)
  • 6가지 버전 모두 수용: 각 셀렉터가 독립 폭을 가져 "통독성경", "개역개정" 같은 긴 이름도 잘리지 않음
  • 버전 셀렉터의 역할이 명확: 모드 탭과 같은 줄에 있어 "이 버전으로 [검색|장절|주제]를 한다"가 시각적으로 묶임
  • 본문 80% 확보: 충분한 압축이지만 무리 없음
  • 이행 위험 낮음: 현재 코드의 4단(헤더/버전/탭/검색)을 3단으로 줄이는 보수적 변경. 동작 동일
  • 대역 본문 표시도 자연: 부 버전 선택 시 본문 카드 안에서 한/영 동시 표시 (현재 구조 유지)
