디자인 결정
  • FAB 위치: 기본 좌상단(`top-3 left-3`). 책 아이콘 + 골드(#B8860B) 테두리로 다른 FAB(스크랩·도구함)와 시각적 구분.
  • 드래그 인터랙션: 길게 누르기(500ms) → 끌어서 4모서리 자석 스냅. 드래그 중 본문 dim + 가이드 점 4개. 위치 localStorage 저장.
  • 탭 시 펼침: FAB 위치 기준 안쪽 방향으로 패널 슬라이드. 좌상단이면 우측+아래로, 우상단이면 좌측+아래로.
  • 컬럼 구조: 최근(0열) → 구약/신약 → 책 → 장 → 절. 0열 상단에 숫자 단축 입력란 (`요3:16` 직타).
  • 컬럼 너비: 모바일 ~220px (5개 컬럼 합), 본문 좌측 일부만 가림. 각 컬럼 세로 스크롤.
  • 최종 선택: 절 탭 → 패널 닫힘 + `mode="chapter" browseStep="verse"` 진입 + 해당 절 자동 스크롤.
  • 닫기: 외부 영역 탭 / 다시 FAB 탭 / ESC / 하드웨어 백.
