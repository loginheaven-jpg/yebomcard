제 추천: C 시안 (검색 우선 sticky bar)

이유:

  • 본문 점유율 78%로 충분히 확보 (현재 50%)
  • 검색이 메인 entry라는 메시지가 명확
  • 버전을 검색 칩 안에 두어 "어느 버전으로 검색하는지" 직관적
  • 모드(검색/장절/주제)는 작은 segment로 충분 — 자주 바꾸는 영역이 아님
  • 병기 토글은 별도 chip으로 분리해 명확성 유지
  • 적용 위험 낮음 — 기존 동작 그대로, 시각만 압축

구현 시 고려: 장절 선택 모드의 "목차로/책 선택" 등은 본문 영역 안에서 처리하거나 모드 진입 시에만 추가 행 표시.
