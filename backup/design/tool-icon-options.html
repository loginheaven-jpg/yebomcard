도구 아이콘 시안 — 8가지

메뉴: 찬송가 · 예배성경 · 성경카드 · 편집 모드
A. 2×2 그리드
앱 모음 의미. 모던하고 중성적.
도구 느낌은 약함.
B. 렌치+드라이버 ★
"도구" 직역. 가장 도구다움.
약간 마초적이나 명확.
C. 렌치 (단일)
간결한 도구 상징.
설정과 약간 겹치는 인상.
D. 도구함 (가방)
"도구함" 직역. 매우 명확.
비즈니스 인상 가능.
E. 막대그래프
통계/대시보드 느낌.
도구 의미 약함.
F. 반짝임 (Sparkles)
"기능 모음" 느낌. AI/마법.
도구 직접성은 낮음.
G. 슬라이더 (조정)
설정/조절 의미.
화면 설정 ⚙와 겹침.
H. 그리드+추가
앱 그리드에 "+" 추가.
확장 가능한 느낌.
추천
★ B (렌치+드라이버) — 도구 의미 가장 강렬, 메뉴 = 작업 도구임을 명확히 표현
D (도구함 가방) — "도구함"이라는 메뉴 이름과 직접 매칭, 의미 가장 정확
A (2×2 그리드, 현재) — 모던하지만 도구 느낌 약함

피해야 할 옵션:
G (슬라이더) — 헤더 ⚙와 의미 중복
F (반짝임) — 도구라기보다 AI/마법
E (막대) — 통계/그래프로 오인
