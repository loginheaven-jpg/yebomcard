최종 명세
  • FAB 위치 2곳: 우상 (top: 138px) ↔ 우하 (bottom: 76px). 길게 누르기로 토글.
  • 패널 위치 고정: FAB 위치와 무관하게 항상 top: 138 / right: 64에서 펼침 (전체화면 버튼 바로 아래). 사용자 인지 일관성.
  • 패널 크기: max-height 60vh로 제한. 상하 양쪽 앱 경계에서 최소 12px 여유.
  • 토글: 길게 누르기 500ms → 반대편으로 점프 + 햅틱 진동(50ms). pointermove 추적 없음 → 모바일 안정적.
  • 탭 동작: 단순 탭 → 패널 토글 (열기/닫기). 길게 누르지 않으면 위치 변경 없음.
  • 컬럼 펼침 방향: FAB의 좌측 (안쪽 방향). FAB가 TR이면 우상 우측에서 좌측으로, BR이면 우하에서 좌측으로.
  • FAB 표시: 닫혀있을 때 골드 테두리 + 작은 ▸ 배지 / 열렸을 때 골드 fill + ◂ (펼침 방향 힌트).
  • 위치 영속: localStorage `yebom_quicknav_pos` = `"tr" | "br"`.
  • 컬럼: 최근 38 / 권 32 / 책 52 / 장 52 / 절 52 = 총 226px. 본문 우측 1/3 정도만 가려짐.
  • 제거: 자유 드래그·4코너 가이드 점·pointermove 핸들러 — 코드 ~45줄 감소.
