#쟁점시안의 선택대안
1'지금' 회차 정의마지막 완료 회차 + 1. 33까지 완료면 34가 지금가장 최근에 읽은 장이 속한 회차 (순서 밖 읽기 존중)
2순서 밖에서 읽은 장36회차 전도서처럼 부분 채움으로 표시. 판정은 장 집합 기준이라 순서 무관플랜 모드에서 읽은 것만 인정 (엄격)
3수동 체크 진입진도표 행 길게 누름 → "종이로 읽음" 체크. 33회차처럼 표기체크박스 직접 탭 (오터치 위험)
4완료 시트마지막 장 3초 열람 시 자동. '잠언 16장 읽기'가 1차 버튼시트 없이 하단 nav 버튼만 '35회차 →'로 바꿈
5그룹 순위 노출이름·순위·회차 전부 공개. 북클럽은 서로 보이는 게 동력내 순위만 보이고 남은 익명 막대 (부담 완화)
6플랜 헤더 위치본문 위 카드. 플랜 모드일 때만 렌더, 목차·검색 진입 시 사라짐QuickNavFab 옆 작은 뱃지로 축소
7절 경계 회차 (39↔40)열왕기하 15장은 양쪽 회차에 속하고, 읽으면 둘 다 채움. 헤더에 '15:22까지'만 표시절 단위 스크롤 위치로 판정 (구현 무거움)
