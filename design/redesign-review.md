# 예봄성경 리디자인 검토 보고서

작성: 시안 `idea_new.html`(After 단독 청사진)을 기준 진실로 두고, 현재 코드베이스(SearchPanel 2039줄 + 12개 면 + 설정/전역)의 모든 기능을 손실 없이 매핑한 종합 설계서. 통합 분석 + 비판 검토를 모두 흡수했다.

---

## 1. 한눈에 보는 결론

시안은 **5탭 IA**(목차/검색/읽기/책갈피/설정) + **종이 메타포 배경**(`#DBD5C8` 캔버스 / `#FBF9F4` 본문) + **얇은 amber 강조**(`#B97E2C`) 로 현재의 화이트/골드 UI를 따뜻한 아이보리/앰버로 갈아끼우는 디자인이다. 사용자 6항(QuickNav 위치 유지, 좌우 스와이프, 책갈피 탭 통합, 본문/주제 세그먼트, 설정 흡수, 전체화면 흡수)을 모두 반영 가능하며, 시안의 빈틈은 통합 분석으로 메웠다. **다만 비판 검토에서 18개 미결과 다수의 회귀 위험이 드러났으니, Phase 1(토큰만) 배포 후 사용 데이터 보고 Phase 2(IA 재편) 진행을 권고**한다. 가장 큰 결정 포인트는 "**전체화면(1절씩) 진입을 설정 안에 묻어도 되는가**" 와 "**5탭 IA 의 단순함과 현재 강점(엔진 배지·6언어·관리자 편집·외부 모니터)을 어디까지 보존할 것인가**" 두 가지다.

### 2-4. 배경색 변화 — 정밀 사양 (중요)

| 레이어 | 현재 | 시안 |

### 3-7. 검색 탭 (사용자 #4)

```
[본문] [주제]   ← 세그먼트 .tseg pill 2개
```

## 5. 사용자 명시 6항 구체 반영안

### #1. QuickNavFab 위치 유지 (TR/BR 토글)
- 색상 토큰만 마이그레이션 (`--paper` bg, `--amber` border, 다크 변수 `--qnav-panel-bg`)
- 5단 cascade, 롱프레스 500ms, 더블탭 250ms, localStorage 위치 — 전부 유지
- 충돌: 시안 우상단 38×38 TTS와 살짝 겹침 가능 → TR 모드 `top: 138px` 헤더 아래라 안전
- **시안 의도와의 충돌 인지**: 시안에는 FAB 자체가 없음. 장기적으로 "목차" 탭이 QuickNav 역할 흡수 가능성 검토
[결정] 살짝 겹치는 것은 괜찮고 더블 클릭으로 이동하는 기능을 유지하자

### #2. 좌우 스와이프 장 이동
- 구현: `.a-read` `touchstart/move/end`
- 활성 영역: 컨테이너 폭의 0.2~0.8 (가장자리 20% 제외 — iOS swipe-back 보호)
- 임계: `|dx| > 50` && 각도 30° 이내 (`|dy/dx| < 0.577`)
- 비활성 조건: `editingVerseId`, isAddingMore, 모달 열림
- 첫 진입 1회 미세 좌우 바운스 힌트 (`yebom_hint_swipe_shown` 가드)
- 키보드 ←/→ 와 같은 `goChapter(delta)` 핸들러 호출
- 데스크탑 마우스 충돌 방지: `touchstart`만 리스닝 (`pointerstart` 금지)
[결정] 데스크탑 기능 유지하고 키보드 좌우 화살표로도 이동하자.

### #3. 책갈피 진입 화면
3-6 참조. 결정 사항:
- 책갈피 배지 = `bookmarks.length` 만 (recent/scrap 별도 카운트)
- 스크랩 진입은 **별도 시트** (시안 패턴 일관)
- 첫 진입 시 "현재 위치 추가" 버튼 amber pulse 1회 (`yebom_hint_bookmark_shown` 가드)

### #4. 검색 통합
3-7 참조. 결정 사항:
- 입력값 모드 전환해도 유지, placeholder만 변경
- 모드 "본문" 고정해도 단어 검색 가능 (parseReference 자동 분기 유지)
- 결과 푸터 "총 N건 · X/Y개 버전 [· 버전당 최대 50건]" 유지
- 자동 포커스: 데스크탑만 (모바일 키보드 펼침 회피)

### #5. 우상단 설정 → 하단 흡수
- GlobalFontSettings 폼 재사용, 진입점만 변경
- `FontContext.showFontSettings` deprecate 가능 (당분간 양쪽 동작)
- `setShowFontSettings(true)` 호출처 grep 후 `setActiveTab("settings")`로 마이그레이션
- 첫 진입 학습된 사용자에게 1회 amber pulse + tooltip "설정은 여기로 옮겼습니다"

### #6. 전체화면 → 설정 흡수
- chapter view 우상단 "전체화면" 버튼 제거
- 설정 시트 "읽기 모드" 섹션에 "전체화면(1절씩 보기) →" 큰 버튼

- 권고 보완: **본문 영역 길게 누르기(500ms) → 전체화면 단축 동선** 추가 (미결 #1)
- 풀스크린 종료 시 진입 전 화면으로 복귀 (현재 chapter view), 진입 경로 설정 시트라도 본문으로
